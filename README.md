# Котодом 🐾

**Котодом** — это уютная 2D изометрическая игра-симулятор жизни домашнего кота. Игра написана на чистом JavaScript без использования игровых движков, с применением современной модульной архитектуры и сборкой через Vite.

## 🎮 Описание игры

Вы играете за котика, который поселился в новом доме. Ваша задача — ухаживать за питомцем: кормить его, давать воду, укладывать спать, следить за чистотой лотка, играть и общаться с другими котами.

### Особенности
- **Измерение потребностей**: 5 основных потребностей (сытость, энергия, лоток, игры, общение)
- **Интерактивный мир**: кликайте по полу для перемещения, используйте клавиши WASD/стрелки для управления
- **Смена дня и ночи**: динамическое освещение и ночной режим
- **Живые персонажи**: главный кот, NPC-кот Барсик, бабочки, птички
- **Система действий**: кормление, сон, игра с клубком, точение когтей и другие
- **Эффекты и частицы**: пузыри с текстом, plumobob над головой, частицы при действиях
- **Адаптивность**: поддержка мобильных устройств с сенсорным управлением

### Ключевые компоненты

#### EventBus
Центральная шина событий для слабой связности компонентов. Компоненты общаются через события вместо прямых вызовов.

```javascript
bus.on('game:start', handler);
bus.emit('toast', { msg: 'Привет!' });
```

#### GameLoop
Игровой цикл с фиксированным шагом обновления и рендерингом через `requestAnimationFrame`.

#### State
Единый источник истины для состояния игры:
- `state.cat` — состояние кота (позиция, потребности, действие)
- `state.npc` — состояние NPC
- `state.world` — состояние мира (миска, объекты)
- `state.needs` — значения потребностей
- `state.meta` — мета-состояние (пауза, старт, имя кота)

#### Renderer
Многослойный рендерер с правильной сортировкой объектов по глубине (depth sorting) для изометрической проекции.

#### Systems Pattern
Игровая логика разделена на независимые системы:
- **NeedsSystem** — декодирование потребностей со временем
- **ActionsSystem** — выполнение действий (кормление, сон)
- **InteractionSystem** — обработка взаимодействий с объектами
- **WorldSystem** — события мира

## 🚀 Запуск проекта

### Требования
- Node.js 18+
- npm или yarn

### Установка

```bash
npm install
```

### Разработка

```bash
npm run dev
```

Откройте браузер по адресу `http://localhost:5173`

### Сборка

```bash
npm run build
```

### Предпросмотр сборки

```bash
npm run preview
```

## 🎮 Управление

| Действие | Клавиши |
|----------|---------|
| Движение | WASD / Стрелки |
| Взаимодействие | E / Клик по объекту |
| Перемещение клик | ЛКМ по полу |
| Пауза | P / Esc |
| Мяукать | M |

## 📦 Технологический стек

- **Vite** — быстрый сборщик и dev-сервер
- **Vanilla JavaScript (ES6+)** — без фреймворков
- **Canvas API** — рендеринг графики
- **CSS3** — стилизация UI
